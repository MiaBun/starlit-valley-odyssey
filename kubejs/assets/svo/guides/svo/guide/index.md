# Start Page

Welcome to Starlit Valley: Odyssey.

You might be wondering, what is this modpack about?

This modpack is basically a extended and heavily modified version of "society: sunlit valley" by chakyl, the name has been changed to starlit valley: odyssey to reflect this concept.
This modpack not only extends the basic modpack with new processing lines and features,
It also adds a full magic and tech progression and provides more in-game documentation!
